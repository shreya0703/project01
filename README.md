# 🎵 myTunes

**myTunes** is a simple, static website that mimics a music and media service landing page. Built as one of my first projects while learning HTML, CSS, and basic JavaScript integration, it showcases layout structure, sectioning, responsive design elements, and use of icons/images.

## 🌐 Live Demo

[Click here to view the live project](https://shreya0703.github.io/project01/)  


## 🚀 Features

- 🎧 Hero section with an introduction
- 🎶 Music section with trial CTA
- 🎬 Video section with autoplay background video
- 🎁 Gift Card section
- 📱 Fully responsive layout (if made responsive)
- 🧭 Navigation links
- 📦 Organized folder structure

## 🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome (for icons)

  
## 🧠 What I Learned

- Structuring HTML pages semantically
- Using external CSS for styling
- Embedding icons with Font Awesome
- Basic use of HTML `<video>` element
- Organizing sections with consistent layout
- Building a footer with multiple columns

## 📝 Notes

- This is a practice project from the early stages of my front-end development journey.
- It was built to get comfortable with HTML and CSS structure and layout.
- Deployment was done to test and showcase the final result live.
